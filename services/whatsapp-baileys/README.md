# خدمة واتساب Baileys المستقلة (VERTEX WhatsApp Service)

خدمة مصغرة مبنية بـ Node.js لإدارة جلسات واتساب المتعددة بدون حظر، متوافقة مع معمارية VERTEX كخدمة سحابية (SaaS).

---

## المعمارية وطريقة العمل

1. **العزل التام:** تعمل الخدمة في بيئة معزولة عن خادم Laravel الأساسي عبر المنفذ `3000`.
2. **إدارة الجلسات:** لكل متجر جلسة فريدة باسم `session_{business_id}`.
3. **توليد QR Code:** يتم إنشاء كود الربط وإرساله عبر Webhook فورياً إلى لوحة تحكم المتجر.
4. **استقبال الرسائل:** أي رسالة واردة يتم إرسالها إلى مسار الويب هوك الخاص بالمتجر:
   `POST /webhooks/whatsapp/{business_id}`
5. **إرسال الرسائل:** يقوم خادم Laravel باستدعاء مسار الإرسال:
   `POST /api/sessions/{session_id}/messages`

---

## التشغيل السريع

```bash
cd services/whatsapp-baileys
npm install
npm start
```
